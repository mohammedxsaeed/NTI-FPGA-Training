# Generic (Parameterized) Counter

A parameterized up-counter (default width = 5) with a self-checking testbench.

## Files

**rtl/**
- `counter.v`

**tb/**
- `counter_tb.v`

## How to Simulate
Open the project in Xilinx Vivado (or any Verilog simulator), add the files in `rtl/` and `tb/` as design/simulation sources, and run behavioral simulation.
