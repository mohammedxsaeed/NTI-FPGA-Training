# Up/Down Counter

An up/down counter implemented in multiple styles (behavioral, structural, and gate-level) built from a shared D flip-flop and next-state logic block, used to compare abstraction levels for the same design.

## Files

**rtl/**
- `Counter_Behavioral.v`
- `D_FF.v`
- `counter2_struct.v`
- `counter_gate_level.v`
- `next_state_D.v`

**tb/**
- `Counter_TB.v`

## How to Simulate
Open the project in Xilinx Vivado (or any Verilog simulator), add the files in `rtl/` and `tb/` as design/simulation sources, and run behavioral simulation.
