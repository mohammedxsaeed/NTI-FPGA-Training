# Sequence Detector — Overlapping vs. Non-Overlapping

Four sequence-detector FSMs comparing Mealy vs. Moore machines and overlapping vs. non-overlapping sequence matching.

## Files

**rtl/**
- `non_overlapping_seq_detector.v`
- `nonoverlapping_seq_detector_moore.v`
- `overlapping_seq_detector.v`
- `overlapping_seq_detector_moore.v`

**tb/**
- `seq_detector_TB.v`

## How to Simulate
Open the project in Xilinx Vivado (or any Verilog simulator), add the files in `rtl/` and `tb/` as design/simulation sources, and run behavioral simulation.
