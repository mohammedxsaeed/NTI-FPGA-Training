# Lab 04 — Top-Level Integrated System

Full integration of the SIPO, PISO, RAM, and ALU modules into a single TOP_SYSTEM data-path, with an accompanying top-level testbench.

## Files

**rtl/**
- `ALU.v`
- `PISO.v`
- `RAM.v`
- `SIPO.v`
- `TOP_SYSTEM.v`

**tb/**
- `TOP_TB.v`

## How to Simulate
Open the project in Xilinx Vivado (or any Verilog simulator), add the files in `rtl/` and `tb/` as design/simulation sources, and run behavioral simulation.
