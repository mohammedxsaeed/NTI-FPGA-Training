# Lab 08 — Bidirectional Memory

A memory module supporting bidirectional (read/write, shared-bus style) data access, with a self-checking testbench.

## Files

**rtl/**
- `memory.v`

**tb/**
- `memory_tb.v`

## How to Simulate
Open the project in Xilinx Vivado (or any Verilog simulator), add the files in `rtl/` and `tb/` as design/simulation sources, and run behavioral simulation.
