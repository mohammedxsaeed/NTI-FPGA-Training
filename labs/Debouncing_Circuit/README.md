# Switch Debouncing Circuit

A digital debouncer for mechanical push-button/switch inputs, filtering out contact bounce before the signal reaches downstream logic.

## Files

**rtl/**
- `debouncing_circuit.v`

**tb/**
- `debouncing_circuit_tb.v`

## How to Simulate
Open the project in Xilinx Vivado (or any Verilog simulator), add the files in `rtl/` and `tb/` as design/simulation sources, and run behavioral simulation.
