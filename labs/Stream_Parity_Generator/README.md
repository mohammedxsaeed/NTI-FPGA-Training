# Streaming Parity Generator

A parity generator that computes parity over a continuous stream of input bits rather than a single fixed-width word.

## Files

**rtl/**
- `stream_parity_gen.v`

**tb/**
- `parity_tb.v`
- `stream_parity_tb.v`

## How to Simulate
Open the project in Xilinx Vivado (or any Verilog simulator), add the files in `rtl/` and `tb/` as design/simulation sources, and run behavioral simulation.
