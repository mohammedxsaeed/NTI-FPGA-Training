# Edge Detector (FSM)

A finite-state-machine based edge detector with its own dedicated testbench.

## Files

**rtl/**
- `edge_detector.v`

**tb/**
- `edge_detector_tb.v`

## How to Simulate
Open the project in Xilinx Vivado (or any Verilog simulator), add the files in `rtl/` and `tb/` as design/simulation sources, and run behavioral simulation.
