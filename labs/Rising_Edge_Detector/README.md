# Rising Edge Detector (Mealy vs. Moore)

Two FSM styles of an edge detector implemented and compared side by side: a Mealy-style detector and a Moore-style detector.

## Files

**rtl/**
- `Rising_edge_mealy.v`
- `Rising_edge_moore.v`

**tb/**
- `Rising_edge_mealy_tb.v`

## How to Simulate
Open the project in Xilinx Vivado (or any Verilog simulator), add the files in `rtl/` and `tb/` as design/simulation sources, and run behavioral simulation.
