# Lab 03 — SIPO + ALU System

Combines a Serial-In Parallel-Out (SIPO) shift register, a Parallel-In Serial-Out (PISO) shift register, RAM, and the ALU into one small data-path, a step toward the Lab 4 top-level system.

## Files

**rtl/**
- `ALU.v`
- `PISO.v`
- `RAM.v`
- `SIPO.v`
- `SIPO_ALU.v`

## How to Simulate
Open the project in Xilinx Vivado (or any Verilog simulator), add the files in `rtl/` as design/simulation sources, and run behavioral simulation.
