# Even Parity Generator (generate block)

A parameterized parity-generator channel built using Verilog `generate` blocks to scale across the configured bit width.

## Files

**rtl/**
- `even_parity_generate.v`

## How to Simulate
Open the project in Xilinx Vivado (or any Verilog simulator), add the files in `rtl/` as design/simulation sources, and run behavioral simulation.
