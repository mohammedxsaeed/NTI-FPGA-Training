# Day 1 — Full Adder

Three implementations of a 1-bit full adder (dataflow, structural/gate-level, and a hierarchical version built from two half-adders), used as the first introduction to Verilog modeling styles.

## Files

**rtl/**
- `FA_1B.v`
- `FA_Struct.v`
- `Full_Adder.v`

## How to Simulate
Open the project in Xilinx Vivado (or any Verilog simulator), add the files in `rtl/` as design/simulation sources, and run behavioral simulation.
