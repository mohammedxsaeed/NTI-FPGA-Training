# FSM-Driven 7-Segment Display

A finite state machine driving a (multi-)7-segment display output.

## Files

**rtl/**
- `FSM.v`
- `FSM_multi_segment.v`

**tb/**
- `FSM_tb.v`

## How to Simulate
Open the project in Xilinx Vivado (or any Verilog simulator), add the files in `rtl/` and `tb/` as design/simulation sources, and run behavioral simulation.
